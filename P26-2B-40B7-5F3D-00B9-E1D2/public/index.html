Diário de Bordo de Projetos

Desenvolva um sistema de registro cronológico de atividades (logbook) voltado para documentar o avanço de projetos de engenharia. A interface permite criar entradas de texto vinculadas ao dia atual, classificar o nível de impedimento técnico encontrado e visualizar uma linha do tempo vertical estilizada em CSS. A autenticação via Discord OAuth2 assegura que cada diário seja privado ao seu autor no banco de dados Cloudflare D1. O backend deve carimbar a data e hora exatas do servidor (UTC) no momento da inserção, impedindo adulteração retroativa de datas pelo cliente, e disponibilizar uma rota de busca textual que filtra entradas antigas por palavras-chave ou intervalo de datas.
